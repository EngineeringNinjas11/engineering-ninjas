# Engineering Ninjas — Easy Article Publishing

The public website is hosted on GitHub Pages. Articles are managed in the existing WordPress.com site and loaded automatically through the WordPress REST API.

## Publish an article
1. Open the Engineering Ninjas WordPress dashboard.
2. Create a new **Post**.
3. Write the article normally using the WordPress editor.
4. Add a **Category** such as Electrical, Mechanical, Civil, MEP, HVAC, Electronics, or Automation.
5. Add a Featured Image if you want a cover image.
6. Publish the post.
7. The GitHub website will display published posts in its Articles page and the matching branch page.

## Important
Do not create an HTML file for every article. Only the site code needs to be maintained in GitHub.
